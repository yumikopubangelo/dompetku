# Database Dompetku (MySQL)

## Struktur Folder
- `migrations/` : File SQL untuk membuat tabel (dijalankan urut sesuai nomor)
- `seeds/`      : Data awal untuk keperluan development dan testing

## Cara Menjalankan
Jika pakai Docker, database otomatis ter-setup saat `make run`.
Tidak perlu menjalankan file SQL secara manual.
