# Alur Kerja Tim

## Branching Strategy
- `main`        : branch produksi (stabil)
- `development` : branch integrasi fitur
- `fitur-*`     : branch masing-masing anggota

## Alur Pull Request
1. Buat branch dari `development`
2. Kerjakan fitur
3. Push dan buat Pull Request ke `development`
4. Anggota lain melakukan code review
5. Merge setelah disetujui minimal 1 reviewer
